# 버블 기반 2D 평면도 생성 QA 체크리스트

## 기능 흐름
- [ ] 버블 모드에서 `평면도 생성` 버튼 클릭 시 2D 모드로 전환된다.
- [ ] 2D 모드에서 생성 중 로딩 화면이 표시된다.
- [ ] 생성 완료 후 2D 편집 화면(Stage)에 방 목록이 렌더링된다.

## 변환 결과
- [ ] 각 버블이 방 단위(`FloorRoom`)로 변환되어 표시된다.
- [ ] 버블 크기(mm/면적)가 2D 방 크기에 반영된다.
- [ ] 버블 연결선이 평면도 연결 관계(문 위치 계산)에 반영된다.

## 편집 진입
- [ ] 생성 직후 2D에서 선택/패닝/줌 동작이 가능하다.
- [ ] 버블 모드에서 연결 도구 사용 중 생성해도 2D 진입 시 기본 선택 도구 상태를 유지한다.

## 예외 처리
- [ ] 버블이 0개일 때 버블 모드 `평면도 생성` 버튼이 비활성화된다.
- [ ] 버블이 0개일 때 2D 빈 화면의 생성 버튼이 비활성화되고 안내 문구가 표시된다.

## 모드 동기화
- [ ] 버블 수정(이동/크기/연결 변경) 후 2D/3D에 변경 사항이 반영된다.
- [ ] AI 수정 적용 후 버블/2D/3D가 동일한 상태를 유지한다.
